# Source notes

This archive contains the Shree Malti Jewellers (श्री मालती ज्वेलर्स) React/Vite source. The main page is implemented in `src/App.jsx`; reusable sections are composed there to keep the project runnable. `src/config.js` contains centrally configured business details and contact placeholders; `src/data/products.js` contains the demo catalogue and prices. Product imagery currently uses remote Unsplash/Pexels images. No verified storefront photograph, `node_modules`, build output, or environment secrets are included.
